# Artillerist Cannon Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every newly summoned Eldritch Cannon use the artificer's Intelligence modifier and proficiency bonus, grant the correct Protector temporary hit points, and restore the free summon after a long rest.

**Architecture:** Add a focused Foundry runtime module that patches the token delta in `dnd5e.preSummonToken`, after the system has prepared its normal summon changes but before the token is created. Keep calculation and merge logic in exported pure functions so Node's built-in test runner can verify the data without launching Foundry; use `dnd5e.preRestCompleted` for native-looking long-rest recovery on existing character items.

**Tech Stack:** JavaScript ES modules, Foundry VTT 13 hooks, dnd5e 5.2.5 activity data, Node.js built-in test runner.

**Spec:** User-reported Artillerist cannon failures in this task; local subclass and cannon compendium records `S6x53wzUQw5QUqrd` and `QVylQx3S1C6DVTUM`.
